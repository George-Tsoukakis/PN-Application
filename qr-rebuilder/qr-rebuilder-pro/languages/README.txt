Translations for QR ReBuilder Pro (text domain: qr-rebuilder-pro).

The plugin's source language is Greek (el). Greek sites need no translation
file; the Greek text in the code is the original.

qr-rebuilder-pro.pot is the translation template, generated from the PHP
sources. JavaScript strings are passed to the browser through PHP
localisation, so they are included. It is regenerated with
tools/make-pot.php in the development repository (not shipped).

Place compiled translations here as qr-rebuilder-pro-<locale>.mo (or
.l10n.php), for example qr-rebuilder-pro-en_US.mo. The plugin loads this
folder with load_plugin_textdomain() on 'init'.
