# Εγκέφαλος PharmacyNeeds

`pharmacyneeds-brain.json`: γνώσεις για PN Chat → Εγκέφαλος → Φόρτωση →
**Προσθήκη**. Το αρχείο δεν περιέχει ρυθμίσεις, οπότε δεν αλλάζει κείμενα ή
συνώνυμα.

Πηγές: readme των PlanDose 1.32.2, QR ReBuilder Pro 2.16.0, ΕΟΦ Ελλείψεις
2.10.1, ο κώδικας του υπολογιστή αποθέματος (theme) και screenshots των σελίδων.

Αλλαγές: διορθώστε το `build-brain.py`, μετά
`python3 build-brain.py && php check-brain.php`. Το `check-brain.php` ελέγχει
ότι κάθε διατύπωση απαντιέται από τη δική της γνώση (μαζί με τις αρχικές
γνώσεις του plugin) και ότι δείγματα ερωτήσεων φτάνουν στη σωστή γνώση.
